# zsh

`additions.zsh` is the only part of `~/.zshrc` kept here: a `gti` alias and the
prompt.

```
~/src/tgwizard/dotfiles master
$
```

## Where

Paste the contents of `additions.zsh` into `~/.zshrc`, below the
`source $ZSH/oh-my-zsh.sh` line. It has to come after that line, since the
Oh My Zsh theme sets `PROMPT` and would otherwise override it.

It relies on Oh My Zsh for `setopt prompt_subst` and the `$fg_bold` colors.
Without Oh My Zsh, add this above it:

    setopt prompt_subst
    autoload -U colors && colors

## Why not the whole zshrc

The rest of `~/.zshrc` is machine-specific: it's generated by the Oh My Zsh
installer and then appended to by tool installers (`PATH` entries for whatever
happens to be installed). Symlinking a full copy breaks on a machine where those
tools are missing, so it isn't in `symlink.py`.
