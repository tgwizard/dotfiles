# zsh

`additions.zsh` is the part of `~/.zshrc` kept here: `EDITOR`, a `gti` alias
and the prompt.

```
~/src/tgwizard/dotfiles master
$
```

Paste it into `~/.zshrc` below `source $ZSH/oh-my-zsh.sh`; the theme sets
`PROMPT` and would otherwise override it. It relies on Oh My Zsh for
`prompt_subst` and the `$fg_bold` colors.

The rest of `~/.zshrc` is machine-specific installer output, so it isn't
tracked.
