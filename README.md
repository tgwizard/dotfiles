# My dotfiles

Copy or symlink into place:

| File | Goes to |
|---|---|
| `git/gitconfig` | `~/.gitconfig` |
| `git/gitignore_global` | `~/.gitignore_global` |
| `ghostty/config` | `~/.config/ghostty/config` |
| `vim/vimrc` | `~/.vimrc` (see `vim/README.md`) |
| `zsh/additions.zsh` | pasted into `~/.zshrc` (see `zsh/README.md`) |
| `ssh/README.md` | reference for `~/.ssh/config` |
